# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
(translations are available at the same address).

In short:

- We treat each other with respect — regardless of experience, background, gender,
  identity, age, religion or views.
- We criticise code and ideas, not people. Constructively and with specifics.
- Not acceptable: harassment, insulting comments, personal attacks, publishing other
  people's private information without consent, sexualised content.
- We help newcomers — everyone was new once.

## Reporting violations

Report violations to the project maintainer privately — via a message on GitHub
(the repository owner's profile). Every report will be handled confidentially.
Maintainers may remove comments, code and issues that violate this code, and in serious
cases ban a person from the project, following the Contributor Covenant guidelines.
